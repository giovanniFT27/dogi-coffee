Conectar con GitHub & CMS

¿Cómo alojar esta web GRATIS en GitHub?

Podrás tener tu propia URL para el código QR de Dogi Coffee y administrar tus productos desde un panel estilo WordPress sin pagar servidores.

1
Crear Repositorio en GitHub Crea un repositorio público con el nombre dogi-coffee y sube este archivo como index.html.
2
Activar GitHub Pages En tu repositorio, ve a Settings > Pages y selecciona la rama main. ¡Tu web estará lista y con HTTPS gratuito!
3
Conectar Panel CMS (Decap CMS) Crea una carpeta llamada admin en tu proyecto con dos archivos:
  • admin/index.html (Carga Decap CMS)
  • admin/config.yml (Configura tus productos)
Tip para imágenes: Puedes subir las imágenes directamente a una carpeta /images en GitHub o usar enlaces directos para mantener todo súper ligero.
